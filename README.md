# Moscow Realty Market Analysis 🏙️

Небольшой учебный **Python-проект по веб-скрейпингу и анализу цен квартир в Москве**. Он собирает публичные объявления с портала [МирКвартир](https://www.mirkvartir.ru/Москва/), очищает данные, считает цену квадратного метра, строит 4 графика и сохраняет результаты в CSV + Markdown-отчёт.

## Что анализируем

- Цена предложения квартиры, ₽
- Общая площадь, м²
- Комнатность (0 = студия)
- Цена за квадратный метр, ₽/м²
- Адрес, район/метро, если указаны и распознаны
- Ссылка на исходное объявление

## Быстрый старт

Установите Python 3.11+ и запустите в терминале:

```bash
python -m pip install -r requirements.txt
python main.py --mode sample
```

**Sample-режим** сразу создаёт таблицу, 4 графика и отчёт из небольшого реального снимка объявлений от 12 ноября 2026 года. Эти объявления были проверены по открытым страницам портала; выборка состоит из **7 записей** и нужна для демонстрации работы кода, **не для выводов о среднем уровне цен всего московского рынка**.

## Сбор новых данных с сайта

```bash
python main.py --mode live --max-pages 2 --delay 4
```

- Скрейпер проверяет `robots.txt`, останавливается, если автоматический доступ запрещён, и соблюдает паузы.
- Работает с открытым HTML страницы, не обращается к приватным API, не обходит капчи и блокировки.
- Если каталог изменил структуру или вернул HTTP 403/429, программа выдаёт понятную ошибку; **живой сбор нельзя гарантировать**. Можно использовать разрешённый экспорт/API источника, согласовав доступ.
- Дополнительные страницы обрабатываются только когда найдена ссылка «Следующая»; не выдумываются URL.
- Не собираем персональные данные продавцов, телефоны, фотографии.

## Работа со своим CSV

```bash
python main.py --input data/real_listings_snapshot.csv --out results
```

CSV должен содержать колонки `url,price_rub,area_m2,rooms`; остальные поля опциональны.

## Тесты

```bash
python -m pytest -q
```

Тесты проверяют распознавание цен, площади и комнатности в примере HTML, поиск следующей страницы и очистку записей. Они **не являются гарантией** работоспособности парсинга при изменении сайта.

## Этика и ограничения исследования

Данные относятся к **ценам объявлений**, а не к ценам фактически совершённых сделок. Несколько объявлений могут относиться к одному объекту. Страницы ранжируются и не образуют случайную репрезентативную выборку. Прежде чем собирать данные, ознакомьтесь с условиями использования сайта и применимым законодательством. Не запускайте частые/массовые запросы.
